1. 是什么：生产规模的开源快照

定位：DeepInfer 是支撑 DeepSeek-V4.1-Flash 大规模线上服务的推理引擎开源版。官方 Q&A 给出的生产规模：单集群每天服务 155 万亿 token，整体营收 38 美元/GPU·小时（谷时电价口径）。

血缘：README 致谢段写明"originally built primarily on vLLM"，另受 SGLang 与 TensorRT-LLM 启发——五层骨架与 vLLM 相同，但为 V4.1-Flash 的 CED/YOCO 架构与大规模部署深度定制。

开源边界：引擎本体（离线推理可用）；KV cache 存储系统与跨副本负载均衡未含（耦合内部基础设施），设计在 doc/inference_deployment_qa.md（312 行）展开；伴生开源 deepseek-recipe（Rust 编解码组件）。硬件：NVIDIA SM100 + 华为昇腾 950（CANN 9.2）。

规模对比：vLLM 主包数百万行级，DeepInfer 主包 4.6 万行——为 V4.1-Flash 单车型调校的引擎；v4_modules 里直写 CED 的投影分发与 SWA 的 ring buffer 语义，是通用框架拿不来的自由。

4. 特性开关全集：environ.py 一个文件看全特性

一文件看全特性（完整字段表见下方 deepinfer/(root) 包的 environ.py 文件卡）：EPLB 组（冗余专家/统计窗口/重排间隔）、投机解码组（USE_NEXTN_DECODE=5 / ENABLE_MTP_VARLEN / MAX_BACKTRACKING / DFLASH_CONFIDENCE_HEAD_TEMPERATURE）、YoCo 组（TRUNCATION_MODE=off|mask|compact + KEEP_TOKENS）、调度组（PREFILL_ATTEMPT_INTERVAL=70 / ANY=100 / ZERO_OVERHEAD_SCHEDULING）、图捕获组（ENFORCE_EAGER / CUDAGRAPH_BATCH_SIZE_INTERVAL=8）、结构化输出组（XGRAMMAR 系列）、状态槽组（NUM_STATE_SLOTS_RATIO=1.2）、批不变（BATCH_INVARIANT，NVIDIA only）。

5. 双平台与 C++ 侧

昇腾一等公民：requirements-ascend.txt 独立依赖、csrc/asc_utils.cpp、npu_ops/patch_imports 把 topk 与视觉注意力替换为 NPU 实现（采样 topk 暂回退 torch，deep_select.py 内 TODO(NPU) 注释）、DEEPINFER_ACCELERATOR=ascend 切换构建。批不变与确定性采样当前 NVIDIA only。
