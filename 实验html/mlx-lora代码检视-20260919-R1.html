① 项目目标与预期

1.1 训练目的

在 Apple M4 16GB 单机、无 CUDA 的条件下，走通「端侧大模型从微调到从零预训练」的完整链路， 并横向对比 纯 Attention 架构 与 Mamba(SSM)+Attention 混合架构 在 相同数据、相同参数量级下的收敛速度、显存占用与长上下文能力。 项目本身是架构与工程可行性验证，不是产出通用大模型。

1.2 要解决的具体问题

  • 显存墙：248K 词表的 logits 在 16GB 统一内存上直接算交叉熵会 OOM —— 用「分块 CE + fp16 + clip」拆解。
  • 无 CUDA 的并行限制：MLX 的 mx.compile / mx.checkpoint 行为与 PyTorch 不同，需实测验证梯度与显存。
  • 两套训练抢算力：需要 50/50 轮班调度，且必须支持 SIGTERM 优雅保存 + 断点自动恢复，否则每次切换都丢进度。
  • 长时无人值守：训练周期以天计，需要看门狗自愈 + 邮件告警，避免静默死亡。
  • 评估闭环：MLX 权重无法直接喂给 lm-eval-harness，需要 MLX→HF 的格式转换（含 RoPE 置换）。

1.4 实验预期效果

  • 收敛速度：Mamba 混合架构在同等 token 数下，loss 应与同规模 Attention 架构持平或略优（预期差距 ±0.15 以内）。
  • 显存：混合架构因 SSM 无 KV Cache，长序列下显存增长应显著慢于纯 Attention。
  • 长上下文：SSM 层理论上具备 O(T) 线性复杂度，外推时衰减应缓于 RoPE Attention 层。
  • 能力上限：受限于 M 级 token 预算（严重欠训），预期模型只能拟合 TinyStories 分布，不具备通用知识。

【用途】 50/50 算力轮班调度器。让 A 线（TinyStories 0.46B）与 B 线（Mamba 混合架构 0.38B）各占 2 小时轮替训练。 通过 PID 单例锁防止双实例并发；通过 marker 文件感知完成态，已完成线直接跳过不空转； 切片到时先发 SIGTERM 让训练脚本优雅保存检查点，最多宽限 180s，仍不退出则 SIGKILL 兜底。
【入参说明】
  • SLICE=7200 — 每片段最长秒数（2 小时）
  • LOCK=/tmp/mlx_alternator.lock — 单例锁文件，内容为调度器 PID
  • run_slice $1 $2...$N — 第 1 个参数为日志文件路径，其余为「环境变量 + 命令」形式，全部交给 env 执行
  • 环境变量透传：START_STEP=auto（自动找最新检查点）、MAX_STEPS、PEAK_LR
#!/bin/bash
# 轮班调度器 v3: 单例锁 + 完成态跳过 + 日志正确重定向
# 用法: nohup bash alternator.sh > alternator.log 2>&1 &
cd "$(dirname "$0")"
PY=.venv/bin/python
SLICE=7200        # 每片段最长 2 小时
LOCK=/tmp/mlx_alternator.lock

# ---- 单例锁: 已有活着的实例则拒绝启动 ----
if [ -f "$LOCK" ] && kill -0 "$(cat $LOCK)" 2>/dev/null; then
  echo "调度器已在运行 (PID $(cat $LOCK)), 拒绝重复启动"
  exit 1
fi
echo $$ > "$LOCK"
trap 'rm -f "$LOCK"; exit 0' EXIT INT TERM

run_slice () {
  # $1=日志文件  其余=环境变量与命令; 真正重定向 stdout/stderr 到日志
  local log="$1"; shift
  env "$@" >> "$log" 2>&1 &
  local pid=$!
  local waited=0
  # 等训练退出(完成/异常提前退出立即返回), 最长 SLICE 秒强制切换
  while kill -0 "$pid" 2>/dev/null && [ "$waited" -lt "$SLICE" ]; do
    sleep 5
    waited=$((waited + 5))
  done
  kill -TERM "$pid" 2>/dev/null     # 训练脚本有 SIGTERM 优雅保存
  # 等待优雅退出最多 180s (保存 4.6GB 检查点需要时间); 卡死则 SIGKILL 兜底
  local grace=0
  while kill -0 "$pid" 2>/dev/null && [ "$grace" -lt 180 ]; do
    sleep 5
    grace=$((grace + 5))
  done
  if kill -0 "$pid" 2>/dev/null; then
    echo "[KILL] 训练未响应 SIGTERM(${grace}s), 强制 SIGKILL"
    kill -KILL "$pid" 2>/dev/null
  fi
  wait "$pid" 2>/dev/null
}

while true; do
  # A 线: TinyStories; marker 存在=已完成, 直接跳过不启动进程
  if [ -f pretrain_ckpt/.done_56570 ]; then
    echo "=== [A] TinyStories 已完成(.done_56570), 跳过 $(date '+%m-%d %H:%M') ==="
  else
    echo "=== [A] TinyStories $(date '+%m-%d %H:%M') ==="
    run_slice pretrain_60m.log \
      START_STEP=auto MAX_STEPS=56570 PEAK_LR=8e-5 \
      $PY -u pretrain.py train
  fi
  sleep 5
  # B 线: Mamba 混合架构
  if [ -f mamba_ckpt/.done_30000 ]; then
    echo "=== [B] Mamba 已完成(.done_30000), 跳过 $(date '+%m-%d %H:%M') ==="
  else
    echo "=== [B] Mamba $(date '+%m-%d %H:%M') ==="
    run_slice mamba_train.log \
      START_STEP=auto MAX_STEPS=30000 PEAK_LR=1.2e-4 \
      $PY -u mamba_hybrid.py train
  fi
  sleep 5
done

"""电子狗 v2: 锁感知 + 告警冷却 (同事故 30 分钟内不重复发)
用法: nohup .venv/bin/python -u watchdog.py > watchdog.log 2>&1 &
巡检 300s; 规则:
  1. 锁文件存在但 PID 死亡        -> 告警"调度器异常退出" + 清锁重启 (一次性)
  2. 无锁且无 alternator 进程     -> 视为调度器未运行, 静默拉起 (不算事故)
  3. 调度器活着但连续 2 轮无训练进程 -> 告警"训练异常" + 重启调度器 (带 30min 冷却)
  4. 训练进程在但日志静默 >30min  -> 告警"疑似卡死" (带 30min 冷却, 不自动杀)
"""
import os
import subprocess
import sys
import time

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
BASE = os.path.dirname(os.path.abspath(__file__))
LOCK = '/tmp/mlx_alternator.lock'
COOLDOWN = 1800  # 同类告警冷却 30 分钟

_last_alert = {}


def procs():
    return subprocess.run(['ps', 'aux'], capture_output=True, text=True).stdout


def alert(key, title, body):
    now = time.time()
    if now - _last_alert.get(key, 0) < COOLDOWN:
        print(f'[告警冷却中] {title}', flush=True)
        return
    _last_alert[key] = now
    try:
        import send_progress
        send_progress.send(title, f'
{body}
')
        print(f'[告警] {title}', flush=True)
    except Exception as e:
        print(f'[告警失败] {e}', flush=True)


def alternator_alive():
    if not os.path.exists(LOCK):
        return False
    try:
        pid = int(open(LOCK).read().strip())
        os.kill(pid, 0)
        return True
    except (ValueError, ProcessLookupError, PermissionError):
        return False


def training_alive():
    ps = procs()
    return ('pretrain.py train' in ps) or ('mamba_hybrid.py train' in ps)


def restart_alternator():
    subprocess.Popen(['nohup', 'bash', 'alternator.sh'],
                     cwd=BASE,
                     stdout=open(f'{BASE}/alternator.log', 'a'),
                     stderr=subprocess.STDOUT)


def main():
    print('电子狗 v2 启动: 300s 巡检, 告警冷却 30min', flush=True)
    no_training_rounds = 0
    while True:
        time.sleep(300)
        try:                                   # 主循环保护: 任何异常不能杀死看门狗
            ps = procs()
            alt_bash = 'alternator.sh' in ps
            lock_ok = alternator_alive()
            training = training_alive()

            if not alt_bash and not lock_ok:
                # 调度器没在跑: 静默拉起 (锁文件不存在不算事故)
                restart_alternator()
                print('[自愈] 调度器未运行, 已拉起', flush=True)
                no_training_rounds = 0
                continue

            if alt_bash and not lock_ok:
                alert('lock', '【mlx-lora-finetune】调度器异常退出',
                      'alternator.sh 进程消失(锁残留), 已自动重启。请检查 alternator.log。')
                restart_alternator()
                no_training_rounds = 0
                continue

            if lock_ok and not alt_bash:
                # 有锁但进程没了: 说明启动中崩溃, 清锁重启
                os.remove(LOCK)
                restart_alternator()
                print('[自愈] 调度器带死锁运行, 已重启', flush=True)
                continue

            # 调度器健康, 检查训练进程
            if not training:
                no_training_rounds += 1
                if no_training_rounds >= 2:  # 10 分钟无训练 (排除 5s 切换间隙)
                    alert('training', '【mlx-lora-finetune】训练异常告警',

                          '请检查 alternator.log 与 pretrain/mamba 日志。')
                    restart_alternator()
                    no_training_rounds = 0
            else:
                no_training_rounds = 0

            # 日志新鲜度: 只检查未完成线的活跃日志 (A 完成 marker 存在则只看 mamba)
            import glob
            logs = []
            if not os.path.exists(f'{BASE}/pretrain_ckpt/.done_56570'):
                logs += glob.glob(f'{BASE}/pretrain_60m.log')
            if not os.path.exists(f'{BASE}/mamba_ckpt/.done_30000'):
                logs += glob.glob(f'{BASE}/mamba_train.log')
            if training and logs:
                stale = max(time.time() - os.path.getmtime(l) for l in logs)
                if stale > 1800:
                    alert('stale', '【mlx-lora-finetune】训练疑似卡死',
                          f'训练进程存在但日志静默 {stale/60:.0f} 分钟。'
                          f'请人工 sample  检查(看门狗不自动杀进程)。')
        except Exception as e:
            # 看门狗自身异常: 打印并存活 (send 走 SMTP 可能网络抖动)
            import traceback
            print(f'[看门狗巡检异常, 已存活] {e}\n{traceback.format_exc()[-500:]}', flush=True)


if __name__ == '__main__':
    main()

# ---------- 数据 ----------

def line_is_junk(line):
    """行级退化过滤: 全行扫描, 同字符连跑>30 或 多样性过低"""
    if len(set(line)) < max(6, len(line) // 25):
        return True
    run, best = 1, 1
    for a, b in zip(line, line[1:]):
        run = run + 1 if a == b else 1
        best = max(best, run)
        if best > 30:
            return True
    return False

分块交叉熵：248K 词表在 16GB 内存下的核心手段

【用途】 248K 词表 × 512 序列 × batch 2 的完整 logits 张量约 4.7GB（fp32），加上反向会直接打爆 16GB。 把序列按 128 token 切块，逐块计算 logits 并立即转 fp16，clip 到 ±30 防止 fp16 溢出，再算交叉熵。

  • x — 输入 token，形状 [B, S]，dtype int32
  • y — 目标 token（x 右移一位），形状 [B, S]，dtype int32
  • 返回：标量 loss，已按 B * S 归一化
    def loss_fn(model, x, y):
        h = model.hidden(x)                          # [B,S,1024] 仅 17MB
        B, S, _ = h.shape
        w = model.embed.weight.T                     # 绑定 embedding, 不再额外存 lm_head
        total = mx.zeros(())
        chunk = 128
        for i in range(0, S, chunk):                 # 分块: 每 128 token 一片
            logits = (h[:, i:i + chunk] @ w).astype(mx.float16)
            logits = mx.clip(logits, -30.0, 30.0).astype(mx.float32)  # fp16 溢出保险丝
            total = total + nn.losses.cross_entropy(logits, y[:, i:i + chunk]).sum()
        return total / (B * S)

【注意】 dt_proj.bias 当前写为 -np.log(np.exp(lin) - 1)。目标是让 softplus(bias) ∈ [1e-3, 1e-1]， 正确解应为 +np.log(np.expm1(lin))（约 [-6.9, -2.25]）。当前符号取反后 softplus(bias) ∈ [2.26, 6.9]， dt 被放大 10~100 倍，离散化 A 会迅速归零，SSM 记忆长度可能被压到接近 1 token。此点已列入「待验证假设」。 
# ---------------- Mamba SSM ----------------
def _ssm_step(h, xt, Bt, Ct, dt, negA, Dv):
    """单步递推: A_bar=exp(dt·A), B_bar=dt·B; y=C·h+D·x (D 项仅此处一次)
    negA/Dv 作为显式参数传入 -> mx.compile 全局一次编译, 所有层复用"""
    d = mx.exp(dt[..., None] * negA)                   # [B,Di,DS] 离散化 A
    new = d * h + dt[..., None] * Bt[:, None, :] * xt[..., None]
    y = (new * Ct[:, None, :]).sum(-1) + Dv * xt       # [B,Di]
    return new, y


_SSM_STEP = mx.compile(_ssm_step)      # 模块级: 避免每层每步重复编译


def ssm_scan(x, B_s, C_s, delta, A, Dv):
    """选择性 SSM 逐token递推
    x: [B,T,Di]  B/C: [B,T,DS]  delta: [B,T,Di]
    A: [Di,DS] 已为负值(调用方传 -exp(A_log), 本函数不再取 exp —— 修复双重exp)
    返回: [B,T,Di]
    """
    Bb, T, Di = x.shape
    h = mx.zeros((Bb, Di, B_s.shape[-1]), dtype=x.dtype)
    ys = []
    for t in range(T):
        h, y = _SSM_STEP(h, x[:, t], B_s[:, t], C_s[:, t], delta[:, t], A, Dv)
        ys.append(y)
    return mx.stack(ys, axis=1)


def causal_conv1d(x, weight, bias):
    """深度可分离因果卷积 k=4: x[B,L,C], weight[C,K]"""
    B, L, C = x.shape
    K = weight.shape[-1]
    pad = mx.concatenate([mx.zeros((B, K - 1, C), x.dtype), x], axis=1)
    y = mx.zeros((B, L, C), x.dtype)
    for k in range(K):
        y = y + pad[:, k:L + k, :] * weight[None, None, :, k]
    return y + bias

class MambaBlock(nn.Module):
    """选择性 SSM 块: 线性复杂度 O(T), 推理时 O(1) 显存/token"""

    def __init__(self, c):
        super().__init__()
        d, di, ds, r = c['hidden'], c['d_inner'], c['d_state'], c['dt_rank']
        K = c['conv_kernel']
        # in_proj 输出: [x(di) | z(di) | B(ds) | C(ds) | dt(r)]
        self.in_proj = nn.Linear(d, 2 * di + 2 * ds + r, bias=False)
        # 恒等初始化: 只有最后一个 tap=1, 初始时 conv=恒等映射 (原来0.5*4会放大2倍)
        w = np.zeros((di, K)); w[:, -1] = 1.0
        self.conv_weight = mx.array(w)
        self.conv_bias = mx.zeros(di)
        self.x_proj = nn.Linear(di, r + 2 * ds, bias=False)
        self.dt_proj = nn.Linear(r, di, bias=True)
        # S4D-real 初始化: A = -arange(1..ds)
        self.A_log = mx.log(mx.tile(mx.arange(1, ds + 1, dtype=mx.float32), (di, 1)))
        self.D = mx.ones(di)
        self.out_proj = nn.Linear(di, d, bias=False)
        # dt_bias 初始化: 使 softplus 后分布于 [1e-3, 1e-1]
        lin = np.linspace(1e-3, 1e-1, di)
        self.dt_proj.bias = mx.array(-np.log(np.exp(lin) - 1))
        self.c = {'di': di, 'ds': ds, 'r': r}   # 维度存dict: MLX Module的int实例属性会被串写!

    def __call__(self, x):
        di, ds = self.c['di'], self.c['ds']
        # 标准 Mamba: in_proj 产生 [x, z]; x 经 conv+silu; B/C/dt 由 x_proj(x_conv) 产生
        # (自审修复: 原 x_proj 是死参数, B/C 直接来自 in_proj 尾部切片偏离选择性设计)
        zx = self.in_proj(x)
        xv, z = zx[..., :di], zx[..., di:2 * di]
        xv = nn.silu(causal_conv1d(xv, self.conv_weight, self.conv_bias))
        dtr, Bq, Cq = mx.split(self.x_proj(xv), [self.c['r'], self.c['r'] + ds], axis=-1)
        dt = nn.softplus(self.dt_proj(dtr))            # [B,T,Di]
        # A = -exp(A_log) 此处取一次即可 (ssm_scan 内不再 exp); D 项在 ssm_scan 内加, 此处不重复
        y = ssm_scan(xv, Bq, Cq, dt, -mx.exp(self.A_log), self.D)
        return self.out_proj(y * nn.silu(z))

def save_all(path, model, opt, step):
    """模型+优化器状态+步数 一起存; 原子写: 临时文件+rename, 不留半截档"""
    d = {}
    for k, v in tree_flatten(model.parameters()):
        d['m.' + k] = v
    for k, v in tree_flatten(opt.state):
        d['o.' + k] = v if hasattr(v, 'astype') else mx.array(v)
    tmp = path.replace('.safetensors', '_tmp.safetensors')
    mx.save_safetensors(tmp, d)
    os.replace(tmp, path)                # 原子替换: 要么旧档要么新档, 无中间态
    with open(f'{CKPT_DIR}/last_step.txt', 'w') as f:
        f.write(str(step))

def send(subject, html_body, attachment_path=None):
    msg = MIMEMultipart("mixed")
    msg["Subject"], msg["From"], msg["To"] = subject, FROM_ADDR, TO_ADDR
    alt = MIMEMultipart("alternative")
    alt.attach(MIMEText(html_body, "html", "utf-8"))
    msg.attach(alt)
    if attachment_path:
        with open(attachment_path, "rb") as f:
            att = MIMEApplication(f.read())
        att.add_header("Content-Disposition", "attachment",
                       filename=("utf-8", "", attachment_path.split("/")[-1]))
        msg.attach(att)
    ctx = ssl.create_default_context()
    with smtplib.SMTP("smtp.163.com", 25, timeout=30) as s:  # 25端口 STARTTLS
        s.ehlo(); s.starttls(context=ctx); s.ehlo()
        s.login(SMTP_USER, SMTP_PASS)
        s.sendmail(FROM_ADDR, [TO_ADDR], msg.as_string())

【用途】 把 MLX 自训权重转成 HuggingFace Llama 格式，使 lm-eval-harness 可以直接加载评估。 核心是 RoPE 的坐标置换：MLX 侧用交错配对 (2i, 2i+1)，HF 侧用半分配对 (i, i+D/2)， 对 q_proj / k_proj 的权重按 head 维度重排即可。转换后已实测 logits 与 MLX 侧等价。 同时写出 config.json / generation_config.json，并从 Qwen 目录拷贝 tokenizer 文件。
【入参说明】

  • mlx_safetensors — 例如 pretrain_ckpt/weights_8000.safetensors
  • out_dir — 输出目录，例如 models/hf_46b_8k，不存在会自动创建
  • MX_CONF — 与 pretrain.py 的 CONF 必须一致（vocab_size 248077 / hidden 1024 / layers 18 / heads 16 / kv_heads 4 / head_dim 64 / ffn 2816 / rope_theta 10000.0）
  • TOKENIZER_SRC — models/Qwen3.5-0.8B-4bit
  • permute_rope(wt, heads, head_dim) — 对单层 q/k 权重做交错→半分配对重排

def convert(mlx_safetensors, out_dir):
    os.makedirs(out_dir, exist_ok=True)
    w = dict(mx.load(mlx_safetensors).items())
    out = {}
    out['model.embed_tokens.weight'] = w['embed.weight']
    out['model.norm.weight'] = w['norm.weight']

    def permute_rope(wt, heads, head_dim):
        # 交错配对 (2i, 2i+1) -> 半分配对 (i, i+D/2): Llama->HF 经典置换
        import numpy as np
        wa = wt.reshape(heads, head_dim, -1)
        idx = list(range(0, head_dim, 2)) + list(range(1, head_dim, 2))
        wa = wa[:, idx, :]
        return mx.array(wa.reshape(heads * head_dim, -1))

    for i in range(MX_CONF['layers']):
        p = f'layers.{i}.'
        h = f'model.layers.{i}.'
        out[h + 'self_attn.q_proj.weight'] = permute_rope(
            w[p + 'attn.q_proj.weight'], MX_CONF['heads'], MX_CONF['head_dim'])
        out[h + 'self_attn.k_proj.weight'] = permute_rope(
            w[p + 'attn.k_proj.weight'], MX_CONF['kv_heads'], MX_CONF['head_dim'])
        out[h + 'self_attn.v_proj.weight'] = w[p + 'attn.v_proj.weight']
        out[h + 'self_attn.o_proj.weight'] = w[p + 'attn.o_proj.weight']
        out[h + 'mlp.gate_proj.weight'] = w[p + 'ffn.gate_proj.weight']
        out[h + 'mlp.up_proj.weight'] = w[p + 'ffn.up_proj.weight']
        out[h + 'mlp.down_proj.weight'] = w[p + 'ffn.down_proj.weight']
        out[h + 'input_layernorm.weight'] = w[p + 'n1.weight']
        out[h + 'post_attention_layernorm.weight'] = w[p + 'n2.weight']
    # lm_head 单独存 (Hermes/llama 支持 tie; 显式写出更稳)
    out['lm_head.weight'] = w['embed.weight']
    out = {k: v.astype(mx.bfloat16) for k, v in out.items()}
    mx.save_safetensors(f'{out_dir}/model.safetensors', out)

    conf = {
        'architectures': ['LlamaForCausalLM'],
        'model_type': 'llama',
        'vocab_size': 248077,
        'hidden_size': 1024,
        'intermediate_size': 2816,
        'num_hidden_layers': 18,
        'num_attention_heads': 16,
        'num_key_value_heads': 4,
        'head_dim': 64,
        'rms_norm_eps': 1e-5,
        'rope_theta': 10000.0,
        'rope_scaling': None,
        'max_position_embeddings': 1024,
        'tie_word_embeddings': False,
        'bos_token_id': 1, 'eos_token_id': 2,
        'torch_dtype': 'bfloat16',
    }
    with open(f'{out_dir}/config.json', 'w') as f:
        json.dump(conf, f, indent=1)

    # tokenizer 文件 (从 Qwen 目录拷贝)
    for fn in ['tokenizer.json', 'tokenizer_config.json', 'chat_template.jinja']:
        src = os.path.join(TOKENIZER_SRC, fn)
        if os.path.exists(src):
            shutil.copy(src, os.path.join(out_dir, fn))
    # generation_config: eos 对齐 tokenizer (248046)
    with open(f'{out_dir}/generation_config.json', 'w') as f:
        json.dump({'eos_token_id': 248046, 'bos_token_id': 1, 'pad_token_id': 248044}, f)

    total = sum(v.size for v in out.values())
    print(f'转换完成: {out_dir} | {len(out)} tensors | {total/1e6:.0f}M params (bf16)')
