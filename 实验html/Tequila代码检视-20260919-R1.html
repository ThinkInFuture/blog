① 项目目标与预期

训练目的

  • 把 Qwen3.5-4B（4.21B 参数）量化层权重压到三值 {-1,0,+1} × scale，用 QAT 找回精度。
  • 用腾讯 Tequila「死区复活」方案替代已废弃的自研三值 QAT，解决 deadzone trapping。
  • 在双 2080 Ti 22GB 消费级硬件上完成训练、评测、部署全闭环。

要解决的问题

  • 旧 QAT 精度 20.0%，远低于 BF16 基线，训练 loss 卡死不再下降。
  • 大量权重被三值化为 0 后，STE 梯度是噪声，永远爬不出死区。
  • 显存、内存、磁盘受限，训练频繁崩溃，需要稳定的自愈与断点续训。

短期落地目标

  • 产出可部署三值模型文件（int8 编码 + 每行 fp16 scale + bf16 bias）。
  • 重建权重与内存评估 bit 级一致（128/128 层验证通过）。
  • lm-eval 全量口径（每项 1000-1400 题）给出统计可解释的成绩。

实验预期效果

  • 三值 QAT 显著优于 PTQ（不训练直接量化）。
  • 解冻层数 4 → 12 → 24 带来统计显著提升。
  • 与 BF16 基线的差距随数据量增加而单调缩小。

已实现能力

  • UltraQuantV2 前向/反向实现，数值梯度检查通过（B 路径有限差分 1.63e-06，零失败）。
  • 量化层替换、解冻控制、seq512 长序列打包、AdamW8bit + cosine 调度。
  • 双卡 device_map 模型并行，显存熔断 + STOP 文件优雅退出 + 自愈续训。
  • 安全 checkpoint（只存可训练参数）+ 滚动清理 + 原子写。
  • 三值部署导出 + HF 目录重建 + bit 级一致性校验。
  • lm-eval 全量评测 + Wilson 95% CI + McNemar 配对检验脚本。

待验证假设

  • group_size=128 分组量化：当前 absmean 未按组 reshape，实际是 per-output-channel（每行一个 scale），group_size 未生效。
  • 哈达玛旋转（Bonsai 核心组件）能否进一步降低量化误差，仅完成 PoC 权重误差对比，未接入训练。
  • STE scale 修正（差 26 倍）是否改善收敛，已实现开关，默认关与官方一致，待消融。
  • KL 蒸馏能否用 35GB teacher logits 替代部分数据堆叠。
  • 端到端全量化（embedding / linear_attn / lm_head）能否保持精度。
  • 2-bit 打包与三值推理加速（当前 F.linear 仍是浮点矩阵乘）。
  • 注意力投影层（q/k/v/o_proj）是否被 skip_keywords 正确排除，待与 Qwen3.5 hybrid attention 结构逐一核对。

M01 模型加载与量化层替换 Python
train_tequila_single.py · replace_linear_layers()
【用途】把模型中的普通 nn.Linear 替换为 UltraQuantLinear，跳过注意力、lm_head、embedding，只量化 MLP。
【入参说明】
  • model：已加载的 HF 因果语言模型（bf16，device_map 已确定）。
  • eps：死区权重偏置系数，默认 1e-3。
  • group_size：分组量化粒度参数（接口预留，当前 forward 未使用）。
def replace_linear_layers(model, eps=1e-3, group_size=128):
    """替换 MLP 中的 nn.Linear 为 UltraQuantLinear"""
    replaced = 0
    # 注意: 需与 Qwen3.5 hybrid attention 结构核对, 确认 q/k/v/o_proj 是否已含于 linear_attn
    skip_keywords = ["linear_attn", "lm_head", "embed_tokens"]
    to_replace = []
    for full_name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            if any(kw in full_name for kw in skip_keywords):
                continue
            to_replace.append((full_name, module))

    for full_name, module in to_replace:
        parts = full_name.split(".")
        parent = model
        for p in parts[:-1]:
            parent = getattr(parent, p)
        child_name = parts[-1]

        quant_layer = UltraQuantLinear(
            module.in_features, module.out_features,
            bias=module.bias is not None, eps=eps, group_size=group_size
        )
        # 复用原权重张量, 省一份显存
        quant_layer.weight = module.weight
        if module.bias is not None:
            quant_layer.bias = module.bias
        setattr(parent, child_name, quant_layer)
        replaced += 1
    return replaced
M02 UltraQuantV2 死区复活核心 Python
train_tequila_single.py · UltraQuantV2
【用途】Tequila 核心：活权重三值化走 STE，死权重变成 eps·W 动态偏置，反向走直接梯度路径，绕开 STE 噪声。
【入参说明】
  • input：待量化权重张量（通常是 nn.Linear.weight）。
  • eps：死区偏置系数，默认 1e-3。
  • scale_corr：论文 Eq3 消融开关，默认 False（与官方逐字节一致）。
def absmean(x):
    """每输出通道一个 scale: [out, in] -> [out, 1]"""
    scale = x.abs().mean([-1], keepdim=True)
    delta = scale / 2
    return scale, delta


class UltraQuantV2(torch.autograd.Function):
    """腾讯 Tequila 核心: dead weights 重新激活为 bias"""
    @staticmethod
    def forward(ctx, input, eps, scale_corr=False):
        original_shape = input.shape
        x = input.reshape(-1, input.shape[-1]) if input.dim() == 2 else input.reshape(input.shape[0], -1)

        scale, delta = absmean(x)
        A = torch.zeros_like(x)
        A[x >= delta] = 1
        A[x <= -delta] = -1
        A = A * scale                       # 活权重 = 符号 * scale

        B = torch.zeros_like(x)
        mask_B = A == 0                     # 死区掩码
        eps_t = torch.tensor(eps, device=x.device, dtype=x.dtype)
        B[mask_B] = eps_t * x[mask_B]       # 死权重 -> eps * 原值, 作为偏置分量

        A = A.reshape(original_shape)
        B = B.reshape(original_shape)
        mask_B = mask_B.reshape(original_shape)

        ctx.save_for_backward(mask_B, eps_t, scale)
        ctx.original_shape = original_shape
        ctx.scale_corr = scale_corr
        return A, B

    @staticmethod
    def backward(ctx, grad_A, grad_B):
        mask_B, eps_t, scale = ctx.saved_tensors
        original_shape = ctx.original_shape

        grad_A = grad_A.reshape(mask_B.shape)
        grad_B = grad_B.reshape(mask_B.shape)

        # 活权重走 STE, 死权重走直接梯度路径, 两者相加
        grad_output = grad_A.clone()
        grad_output[mask_B] = grad_output[mask_B] + eps_t * grad_B[mask_B]

        # 官方注释掉的 scale 修正: 默认关闭保持与官方一致
        if ctx.scale_corr:
            gscale = torch.ones_like(grad_output) * scale
            gscale[mask_B] = 1
            grad_output = grad_output * gscale

        grad_output = grad_output.reshape(original_shape)
        return grad_output, None, None
M03 UltraQuantLinear 前向与偏置融合 Python
train_tequila_single.py · UltraQuantLinear
【用途】量化线性层：B.sum(dim=-1) 等价于 ones @ B.T，避免每层每步一次全量 matmul；推理时可离线 fuse 进 bias。
【入参说明】
  • input_：激活张量，形状 [..., in_features]。
  • self.weight：bf16 master weight，前向时实时三值化。
  • self.eps：死区偏置系数。
  • self.bias：原层 bias，可选。
class UltraQuantLinear(nn.Linear):
    """output = X @ A + rowsum(B) + bias"""

    def __init__(self, in_features, out_features, bias=False, eps=1e-3, group_size=128):
        super().__init__(in_features, out_features, bias=bias)
        self.eps = eps
        self.group_size = group_size    # 接口预留, 当前 forward 未使用

    def forward(self, input_):
        A, B = UltraQuantV2.apply(self.weight, self.eps)
        A = A.to(input_.dtype)
        B = B.to(input_.dtype)
        # B.sum 等价 ones @ B.T, 免一次 matmul; 推理可离线 fuse
        out = F.linear(input_, A) + B.sum(dim=-1)
        if self.bias is not None:
            out = out + self.bias
        return out
M04 数据集加载（只载 token） Python

【用途】只加载 input_ids + attention_mask（约 100MB），避免 35GB teacher logits 进入内存；首次提取后缓存，原子写防中断损坏。
【入参说明】
  • chunks_dir：原始 chunk 目录。
  • cache_path：提取后的 token 缓存路径。
  • max_samples：可选，限制样本数（调试用）。
class SlimTokenDataset(Dataset):
    def __init__(self, chunks_dir, cache_path="cache/input_ids_only.pt", max_samples=None):
        if os.path.exists(cache_path):
            payload = torch.load(cache_path, map_location="cpu", weights_only=True)
            self.input_ids = payload["input_ids"]
            self.attention_mask = payload["attention_mask"]
        else:
            import glob
            chunk_files = sorted(glob.glob(os.path.join(chunks_dir, "chunk_*.pt")))
            ids_list, mask_list = [], []
            for cf in chunk_files:
                d = torch.load(cf, map_location="cpu", weights_only=True)
                ids_list.extend(item["input_ids"] for item in d)
                mask_list.extend(item["attention_mask"] for item in d)
                del d
            self.input_ids = torch.cat(ids_list, dim=0)
            self.attention_mask = torch.cat(mask_list, dim=0)
            # 原子写: 先写 .tmp 再 os.replace, 防中途被杀留下损坏缓存
            tmp_path = cache_path + ".tmp"
            torch.save({"input_ids": self.input_ids,
                        "attention_mask": self.attention_mask}, tmp_path)
            os.replace(tmp_path, cache_path)

        if max_samples:
            self.input_ids = self.input_ids[:max_samples]
            self.attention_mask = self.attention_mask[:max_samples]

    def __len__(self):
        return len(self.input_ids)

    def __getitem__(self, idx):
        return {"input_ids": self.input_ids[idx],
                "attention_mask": self.attention_mask[idx]}


def collate_fn(batch):
    return {
        "input_ids": torch.stack([b["input_ids"] for b in batch]),
        "attention_mask": torch.stack([b["attention_mask"] for b in batch]),
    }

M06 安全 Checkpoint 与滚动清理 Python
train_tequila_single.py · save_checkpoint() / load_checkpoint()
【用途】只保存可训练参数（566MB~1.7GB），冻结参数恢复时从原始模型重载；原子写 + 滚动保留最近 3 个，防止磁盘堆爆。
【入参说明】
  • model / optimizer / lr_scheduler：当前训练状态。
  • step：当前训练步数。
  • path：目标 checkpoint 路径。
  • load_optimizer：是否恢复优化器状态（AdamW8bit 状态可能把显存顶到 20GB+）。
def save_checkpoint(model, optimizer, lr_scheduler, step, path, log_obj):
    t0 = time.time()
    model_state = {
        name: p.data.detach().cpu().clone()
        for name, p in model.named_parameters() if p.requires_grad
    }
    state = {
        "step": step,
        "model": model_state,
        "optimizer": optimizer.state_dict(),
        "scheduler": lr_scheduler.state_dict(),
    }
    # 原子写: 先 .tmp 再 replace, 防中断产生 0MB/截断文件
    torch.save(state, path + ".tmp")
    os.replace(path + ".tmp", path)

    # 滚动清理: 只保留最近 3 个, final/deploy 保留
    import glob as _glob
    olds = sorted(_glob.glob(os.path.join(os.path.dirname(path), 'tequila_*.pt')),
                  key=os.path.getmtime)
    for old in olds[:-3]:
        if 'final' not in old and 'deploy' not in old:
            try:
                os.remove(old)
            except OSError:
                pass
    log_obj.info(f"  Saved checkpoint ({time.time()-t0:.1f}s): {path}")


def load_checkpoint(model, optimizer, lr_scheduler, path, log_obj, load_optimizer=True):
    ckpt = torch.load(path, map_location="cpu")
    model_state = ckpt.get("model", {})
    n_loaded = 0
    for name, param in model.named_parameters():
        if name in model_state:
            param.data.copy_(model_state[name].to(param.device))
            n_loaded += 1
    if load_optimizer and "optimizer" in ckpt:
        optimizer.load_state_dict(ckpt["optimizer"])
    if "scheduler" in ckpt:
        lr_scheduler.load_state_dict(ckpt["scheduler"])
    start_step = ckpt.get("step", 0)
    del ckpt, model_state
    gc.collect()
    log_obj.info(f"Resumed {n_loaded} tensors from step {start_step}: {path}")
    return start_step
M07 双卡显存监控与熔断 Python
gpu_monitor_dual.py · main() 核心片段
【用途】轮询 nvidia-smi，任一卡显存超阈值写 STOP 文件请求训练优雅退出；显存回落自动撤销 STOP；超时未退才强杀。
【入参说明】
  • --threshold_gb：单卡显存阈值（GB），当前由日循环传入 99，实际未生效。
  • --check_interval：轮询间隔秒数，默认 3。
  • --grace_sec：写 STOP 后等待退出的秒数，默认 300。
while True:
    time.sleep(args.check_interval)

    ret = proc.poll()
    if ret is not None:
        exit_reason = f"training exited (code {ret}); 重启由日循环管理器负责"
        break

    gpus = get_gpu_usage()
    if not gpus:
        continue

    over = [g for g in gpus if g[1] > threshold_mb]

    # 熔断: 任一卡超阈值 -> 优雅停止 (启动豁免期内不告警)
    if over and not stop_sent and time.time() - launch_time > startup_grace:
        worst = max(over, key=lambda g: g[1])
        log.warning(f"VRAM ALERT on GPU {worst[0]}: {worst[1]/1024:.1f}GB")
        with open(STOP_FILE, 'w') as f:
            f.write(str(time.time()))
        stop_sent = True
        stop_sent_at = time.time()
        continue

    # STOP 已发送: 显存回落撤销, 超时强杀
    if stop_sent:
        peak_now = max((g[1] for g in gpus), default=0)
        if peak_now < threshold_mb * 0.95:
            log.info("VRAM back under threshold, canceling STOP")
            stop_sent = False
            if os.path.exists(STOP_FILE):
                os.remove(STOP_FILE)
        elif time.time() - stop_sent_at > args.grace_sec:
            log.warning("Training did not exit in grace, force killing...")
            kill_process_tree(proc.pid)
            break
        continue

def row_hashes(ids: torch.Tensor):
    """每行哈希: sha1 前 8 字节 -> int64"""
    b = ids.contiguous().view(torch.uint8).numpy().tobytes()
    # 注意: ids 为 int64, 每 token 8 字节; 此处若写 *4 会导致行切片错位
    row_bytes = ids.shape[1] * ids.element_size()
    return [int.from_bytes(hashlib.sha1(b[i*row_bytes:(i+1)*row_bytes]).digest()[:8], 'big')
            for i in range(ids.shape[0])]


def main():
    d = torch.load(CORPUS, map_location='cpu', weights_only=True)
    ids = d['input_ids']

    # 1. 行级精确去重
    hs = row_hashes(ids)
    seen, dup_idx = set(), []
    for i, h in enumerate(hs):
        if h in seen:
            dup_idx.append(i)
        else:
            seen.add(h)
    if dup_idx:
        keep = torch.ones(ids.shape[0], dtype=torch.bool)
        keep[torch.tensor(dup_idx)] = False
        ids = ids[keep]

    # 2. 语料 shingle 哈希集

    corp_set = set()
    for i in range(sh_bytes.shape[0]):
        corp_set.add(int.from_bytes(hashlib.sha1(sh_bytes[i]).digest()[:8], 'big'))

    # 3. 评测题污染检查

def wilson_ci(p, n, z=1.96):
    """Wilson 95% 置信区间"""
    if n == 0:
        return (0.0, 0.0)
    den = 1 + z**2 / n
    center = (p + z**2 / (2 * n)) / den
    half = z * math.sqrt(p * (1 - p) / n + z**2 / (4 * n**2)) / den
    return (center - half, center + half)


def mcnemar_p(b, c):
    """McNemar 精确检验(双侧)"""
    n = b + c
    if n == 0:
        return 1.0
    k = min(b, c)
    return min(1.0, sum(math.comb(n, i) for i in range(0, k + 1)) / 2**(n - 1))

【用途】用参考实现（恒等 STE + B 可微路径）和有限差分分别验证 UltraQuantV2 的自定义 backward，覆盖官方行为（ModeA）与论文 Eq3（ModeB）两种模式。
【入参说明】

  • x：激活张量。

def ste_ref(w, x, scale_corr):
    """参考实现: 硬量化常数 + 恒等 STE 残差 + B 可微路径"""
    with torch.no_grad():
        scale, delta = absmean(w)
        hard = torch.zeros_like(w)
        hard[w >= delta] = 1
        hard[w <= -delta] = -1
        mask = hard == 0
        scale_vec = scale.squeeze(-1)
    # 每位置 STE 缩放: 活=scale(ModeB) 或 1(ModeA), 死=1
    per_pos = scale_vec.unsqueeze(1) if scale_corr else torch.ones_like(w)
    per_pos = torch.where(mask, torch.ones_like(per_pos), per_pos)
    A_const = (hard * per_pos).detach()
    A_ref = A_const + (w - w.detach()) * per_pos
    B_ref = torch.where(mask, EPS * w, torch.zeros_like(w))
    return (F.linear(x, A_ref) + B_ref.sum(dim=-1)).sum()


def run_case(corr, seeds=(42, 1234, 20260916)):
    max_rel, min_cos, fd_max_rel = 0.0, 2.0, 0.0
    for seed in seeds:
        torch.manual_seed(seed)
        w = (torch.randn(OUT, IN, device=DEV) * 0.05).requires_grad_(True)
        x = torch.randn(B_, IN, device=DEV)

        # 自定义 backward
        w1 = w.detach().clone().requires_grad_(True)
        A, B = UltraQuantV2.apply(w1, EPS, corr)
        (F.linear(x, A) + B.sum(dim=-1)).sum().backward()
        g_custom = w1.grad.detach()

        # 参考实现
        w2 = w.detach().clone().requires_grad_(True)
        ste_ref(w2, x, corr).backward()
        g_ref = w2.grad.detach()

        rel = (g_custom - g_ref).norm() / g_ref.norm().clamp_min(1e-12)
        cos = torch.nn.functional.cosine_similarity(
            g_custom.flatten(), g_ref.flatten(), dim=0)
        max_rel = max(max_rel, rel.item())
        min_cos = min(min_cos, cos.item())

        # B 路径有限差分(跳过量化边界附近的死权重)
        with torch.no_grad():
            s, d = absmean(w)
            Am = torch.zeros_like(w)
            Am[w >= d] = 1
            Am[w <= -d] = -1
            Am = Am * s
            dead = (Am == 0).nonzero()
        w3 = w.detach().clone().requires_grad_(True)
        (_, B3) = UltraQuantV2.apply(w3, EPS, corr)
        B3.sum(dim=-1).sum().backward()
        h = 1e-4
        safe = [ij for ij in dead.tolist()
                if abs(abs(w[ij[0], ij[1]].item()) - d[ij[0], 0].item()) > 10 * h]
        for o, j in safe[::max(1, len(safe) // 24)]:
            wp = w.detach().clone(); wp[o, j] += h
            wm = w.detach().clone(); wm[o, j] -= h
            num = (loss_B_only(wp) - loss_B_only(wm)) / (2 * h)
            ana = w3.grad[o, j]

    return max_rel, min_cos, fd_max_rel
M15 哈达玛旋转 PoC Python

【用途】纯 CPU 数学验证：分块 128 列哈达玛旋转能否降低三值量化重建误差，为 Bonsai 系旋转预处理提供本地数据。
【入参说明】

  • H128：归一化 128×128 哈达玛矩阵。
  • n_blocks：in // 128，余数列不旋转原样量化。
def hadamard_128(device):
    H = torch.linalg.hadamard(128).float()          # [128,128], 元素 ±1
    return (H / (128 ** 0.5)).to(device)            # 归一化正交


def ternary_quant_error(w):
    """当前方案(与 UltraQuantV2 同口径): 返回相对误差"""
    scale, delta = absmean(w)
    A = torch.zeros_like(w)
    A[w >= delta] = 1
    A[w <= -delta] = -1
    Q = A * scale
    return ((w - Q).norm() / w.norm().clamp_min(1e-12)).item()


def ternary_quant_error_hadamard(w, H128):
    """分块哈达玛旋转版: 每 128 列一组旋转后量化, 误差在旋转空间度量"""
    out_features, in_features = w.shape
    n_blocks = in_features // 128
    err_sq, norm_sq = 0.0, 0.0
    for b in range(n_blocks):
        blk = w[:, b*128:(b+1)*128] @ H128          # 旋转
        scale, delta = absmean(blk)
        A = torch.zeros_like(blk)
        A[blk >= delta] = 1
        A[blk <= -delta] = -1
        Q = A * scale
        err_sq += ((blk - Q).norm() ** 2).item()
        norm_sq += (blk.norm() ** 2).item()
    if in_features % 128:                            # 余数列不旋转
        rest = w[:, n_blocks*128:]
        scale, delta = absmean(rest)
        A = torch.zeros_like(rest)
        A[rest >= delta] = 1
        A[rest <= -delta] = -1
        Q = A * scale
        err_sq += ((rest - Q).norm() ** 2).item()
        norm_sq += (rest.norm() ** 2).item()
    return (err_sq ** 0.5) / (norm_sq ** 0.5)
