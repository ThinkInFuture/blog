一、项目目标与预期

1.1 训练目的

要解决的核心问题 大语言模型推理时，简单题用大模型是浪费算力，难题用小模型又做不对。传统「路由方案」（RouteLLM、GlimpRouter）在解题前就决定用哪个模型，无法感知题目在推理中途才暴露的难度。本项目要训练一个 4B 小模型，让它在推理过程中自主判断能力边界，遇到卡点时输出控制 token <|llm_offload|>，触发一次对大模型的单次交接，从而在几乎不损失准确率的前提下把大模型调用成本降低 90%+。

1.2 短期落地目标

  • 链路目标：本地跑通「4B 小模型 + 27B 大模型」协同推理协议，不调用任何云端 API，只用自有显卡与电费。
  • 训练目标：完成 Stage 1（锚点嵌入）+ Stage 2（双语料 SFT），产出会按授权提示触发求助的 SFT 模型。
  • 验证目标：在 AMC / Olympiad / AIME 难题集上扫描 offload 触发率，验证「难题触发、easy 题不触发」的行为模式。
  • 待攻关：Stage 3 成本感知 GRPO 的稳定实现（训练环境需真实调用 27B 执行交接）。

2.4 训练方案

三阶段渐进训练
  1. Stage 1 控制 token 嵌入学习：词表新增 <|llm_offload|>，锚点初始化把嵌入放在自然断点 token 家族附近，语义上「住对地方」。
  2. Stage 2 双语料 SFT 行为冷启动：Corpus A（无授权提示 + 完整独立推理）保住独立推理能力；Corpus B'（授权提示 + hard 题 CoT 插 1~4 个 τ_off）教会求助动作。easy 题即使授权也绝不插。
  3. Stage 3 成本感知 GRPO：每题采样 G 条轨迹，奖励 = 答对(0/1) − λ×(协作成本 / 纯大模型成本)，小模型交接前每个 token 双重计费。

2.5 关键约束

必须遵守的工程约束
  • 引擎一致性：自训模型的 offload 行为验证必须用 transformers 引擎，llama.cpp 对新架构存在引擎级差异（永不触发）。
  • Windows 线性注意力：qwen3.5 依赖 fla+Triton，不可用时静默回退 CPU，训练须强制走 transformers 的 torch 回退实现。
  • 磁盘管理：磁盘满会导致 transformers 加载模型报 FileNotFound，checkpoint 需滚动保留最近 2 个。
  • 窗口调度：训练窗口 18:00–次日 06:00，白天自动停训并释放 GPU。
  • 协同协议上限：至多一次交接，不回头，避免无限循环。

M1 数据准备：双语料构建

scripts/train_data_prep.py
【用途】 将 EasyHard-24k 的 math 子集转换为 PyroDash Stage1+2 训练语料。按数据源文件真实标记难度（easy 文件不插 τ_off，hard 文件才插），生成 Corpus A（独立推理）与 Corpus B'（授权模式）双语料，输出 messages 格式的 JSONL 供 TRL 直接使用。
【入参说明】
  • 输入：datasets/easyhard-24k/{math_easy.jsonl, dapo_math_easy.jsonl, math_hard.jsonl}
  • 输出：data/train_sft.jsonl（每行一条 messages 样本，附 corpus/difficulty 元字段）

# -*- coding: utf-8 -*-
"""EasyHard-24k math 子集 -> PyroDash Stage1+2 训练数据 (v2, 评审修复版)

P0-3 修复: easy/hard 用数据源文件真实标记 (easy 文件不插 τ_off,
          hard 文件才插), 修复原版 `or True` 恒真导致 easy 题也插的防滥用违规。
P2-15 修复: 保守切分 (只在句号+空格 / 双换行处切), 保留原分隔符, 不破坏格式。

Corpus A: 原始 system, 无 tau_off (保独立推理)
Corpus B': offload system 提示; hard 样本 CoT 内动态插入 1~4 个 tau_off;
           easy 样本授权提示但轨迹无 tau_off (学"授权时不滥用")
输出: data/train_sft.jsonl (messages 格式)
"""
import json
import os
import random
import re

random.seed(42)

BASE = r"D:\project\2026\202609\Small_ask_big"
DS = os.path.join(BASE, "datasets", "easyhard-24k")
OUT = os.path.join(BASE, "data", "train_sft.jsonl")
TAU = "<|llm_offload|>"

SYSTEM_A = "You are a helpful math assistant."
SYSTEM_B = (
    "You are a helpful assistant. Solve the given problem step by step. "
    "For very difficult steps, you can output <|llm_offload|> to request help "
    "from a more capable model."
)

# P2-15: 保守切分 - 句号/问号/感叹号 + 空白, 或换行; 用 split 保留分隔符
SENT_SPLIT = re.compile(r"(?<=[.!?])\s+|\n")


# 在思维链文本的 n 个指定位置插入 τ_off 交接标记(授权模式的核心动作)
def insert_tau(cot_text, n):
    """在 CoT 句子边界随机插 n 个 tau_off, 保留原分隔符。"""
    parts = SENT_SPLIT.split(cot_text)
    if len(parts) < 3:
        return None
    cands = list(range(1, len(parts)))
    n = min(n, len(cands))
    pos = set(random.sample(cands, n))
    out = []
    for i, s in enumerate(parts):
        out.append(s)
        if i in pos:
            # 用与原文一致的连接方式补 tau (换行切分 -> 换行, 空格切分 -> 空格)
            sep = "\n" if "\n" in cot_text else " "
            out.append(sep + TAU)
    text = "".join(out)
    return text if TAU in text else None


def load_jsonl(p):
    rows = []
    with open(p, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                rows.append(json.loads(line))
    return rows


# 主流程: 读 easy/hard 双源 -> 分别构建语料 A(独立推理)/B(授权模式) -> 打乱落盘
def main():
    os.makedirs(os.path.dirname(OUT), exist_ok=True)
    # 数据源文件即难度标签 (P0-3: 真实 easy/hard, 不再恒真)
    easy = load_jsonl(os.path.join(DS, "math_easy.jsonl"))          # base 答对
    dapo = load_jsonl(os.path.join(DS, "dapo_math_easy.jsonl"))     # 精调后答对 = easy
    hard = load_jsonl(os.path.join(DS, "math_hard.jsonl"))          # base 答错, 已重构
    random.shuffle(dapo)
    dapo = dapo[:1200]

    tagged = ([(r, "easy") for r in easy] +
              [(r, "easy") for r in dapo] +
              [(r, "hard") for r in hard])
    random.shuffle(tagged)

    data = []
    n_b_easy = 0   # B' 中 easy (授权但不求助) 条数
    n_b_hard = 0   # B' 中 hard (含 τ_off 插入) 条数
    for r, difficulty in tagged:
        msgs = r["messages"]
        if len(msgs) < 3:
            continue
        user, assistant = msgs[1], msgs[-1]
        q, a = user["content"], assistant["content"]
        if not q or not a:
            continue
        a_clean = a.replace(TAU, "")
        # ---- Corpus A: 独立推理 ----
        data.append({
            "messages": [
                {"role": "system", "content": SYSTEM_A},
                {"role": "user", "content": q},
                {"role": "assistant", "content": a_clean},
            ],
            "corpus": "A", "difficulty": difficulty,
        })
        # ---- Corpus B': 授权模式 ----
        if difficulty == "hard":
            n_ins = random.randint(1, 4)
            n_ins = min(n_ins, max(1, len(SENT_SPLIT.split(a_clean)) // 4))
            a_b = insert_tau(a_clean, n_ins)
        else:
            a_b = a_clean          # easy: 授权但绝不求助 (P0-3 防滥用核心)
        if a_b is None:
            continue
        if TAU in a_b:
            n_b_hard += 1
        else:
            n_b_easy += 1
        data.append({
            "messages": [
                {"role": "system", "content": SYSTEM_B},
                {"role": "user", "content": q},
                {"role": "assistant", "content": a_b},
            ],
            "corpus": "B", "difficulty": difficulty,
        })

    random.shuffle(data)
    with open(OUT, "w", encoding="utf-8") as f:
# 混合打乱后统一写出 jsonl, 供 Stage1+2 SFT 直接消费
        for d in data:
            f.write(json.dumps(d, ensure_ascii=False) + "\n")

    print(f"total={len(data)} B_easy_no_tau={n_b_easy} B_hard_with_tau={n_b_hard} -> {OUT}")


if __name__ == "__main__":
    main()

# 数据集: 逐行读 jsonl(prompt+response), 训练时只对 response 段计算 loss
class SFTData(Dataset):
    def __init__(self, path, tok):
        self.rows = []
        with open(path, encoding="utf-8") as f:
            for line in f:
                self.rows.append(json.loads(line))
        self.tok = tok

    def __len__(self):
        return len(self.rows)

    def __getitem__(self, i):
        r = self.rows[i]
        m = r["messages"]
        # P0-4: prompt 带 <think>\n, 与评估/推理协议(chat_template enable_thinking)统一
        prompt = (
            f"<|im_start|>system\n{m[0]['content']}<|im_end|>\n"
            f"<|im_start|>user\n{m[1]['content']}<|im_end|>\n"
            f"<|im_start|>assistant\n<think>\n"
        )
        target = m[2]["content"]
        # 目标若以 <think> 开头则剥掉 (避免与 prompt 尾的 <think>\n 重复)
        if target.startswith("<think>"):
            target = target[len("<think>"):]
        if target.startswith("\n"):
            target = target[1:]
        target = target + "<|im_end|>"
        p_ids = self.tok(prompt, add_special_tokens=False)["input_ids"]
        t_ids = self.tok(target, add_special_tokens=False)["input_ids"]
        ids = (p_ids + t_ids)[:MAX_LEN]
        labels = [-100] * len(p_ids) + t_ids[:]
        labels = labels[:MAX_LEN]
        return {"input_ids": ids, "labels": labels}


# 动态 padding 到批内最长; labels 中 pad 位置置 -100, 不参与 loss
def collate(batch, pad_id):
    ml = max(len(b["input_ids"]) for b in batch)
    input_ids, labels, attn = [], [], []
    for b in batch:
        n = ml - len(b["input_ids"])
        input_ids.append(b["input_ids"] + [pad_id] * n)
        labels.append(b["labels"] + [-100] * n)
        attn.append([1] * len(b["input_ids"]) + [0] * n)
    return (torch.tensor(input_ids), torch.tensor(labels), torch.tensor(attn))


# 主流程: 加载 Qwen3.5-4B -> 词表扩 tau_off 锚点初始化(冻结嵌入) -> 挂 LoRA -> 训练

    ap = argparse.ArgumentParser()
    ap.add_argument('--resume', default='')
    ap.add_argument('--start-step', type=int, default=0)
    ap.add_argument('--epochs', type=int, default=0)

    from transformers import AutoModelForCausalLM, AutoTokenizer
    from peft import LoraConfig, get_peft_model

    torch.manual_seed(42)
    random.seed(42)

    log.info("loading tokenizer/base model...")
    tok = AutoTokenizer.from_pretrained(MODEL_DIR, trust_remote_code=True)
    if TAU not in tok.get_vocab():

        log.info("added %s to tokenizer", TAU)

    model = AutoModelForCausalLM.from_pretrained(
        MODEL_DIR, torch_dtype=torch.bfloat16, trust_remote_code=True,
        attn_implementation="sdpa").cuda()
    model.resize_token_embeddings(len(tok))
    # 锚点初始化: tau_off 嵌入 = 句号/换行/endoftext 均值 + N(0, 0.1^2)
    with torch.no_grad():
        w = model.get_input_embeddings().weight
        tid = tok.get_vocab()[TAU]
        anchors = []
    # 锚点初始化: 新 token 嵌入用常见终止符嵌入均值初始化, 语义上接近"回答结束"
        for a in [".", "\n", "<|im_end|>", "<|endoftext|>"]:
            if a in tok.get_vocab():
                anchors.append(w[tok.get_vocab()[a]].float())
        mean_emb = torch.stack(anchors).mean(0)
        w[tid] = (mean_emb + torch.randn_like(mean_emb) * 0.1).to(w.dtype)
        # tied lm_head 同表自动同步
    log.info("tau_off id=%d initialized (anchor mean+noise)", tid)

    lcfg = LoraConfig(
        r=16, lora_alpha=32, lora_dropout=0.05, bias="none",
        target_modules=["q_proj", "k_proj", "v_proj", "o_proj",
                        "gate_proj", "up_proj", "down_proj"],
        task_type="CAUSAL_LM")
    if args.resume:
        from peft import PeftModel
        model = PeftModel.from_pretrained(model, args.resume, is_trainable=True)

def extract_answer(text):

def score_num(pred, gt):
    def norm(x):
        x = str(x).strip().strip(".").replace(",", "").replace("$", "").replace(" ", "")
        try:
            return float(x)
        except ValueError:
            return None
    a, b = norm(pred), norm(gt)
    if a is None or b is None:
        return int(str(pred).strip() == str(gt).strip())
    return int(abs(a - b) < 1e-6)


# 全大模型成本基线: 不 offload 直接问大模型的 token 计价, 作为对照
def llm_full_cost(q):
    """P1-8: 预计算 llm-only 基线成本 (纯大模型解该题的真实成本), 固定缓存。"""
    base = json.load(open(BASELINE, encoding="utf-8")) if os.path.exists(BASELINE) else {}

        return base[q]
    body = {"model": "qwen3.8-27b",

            "max_tokens": MAX_NEW, "temperature": 0.1}

# 交接: 小模型 partial 输出加 stop 标记, 由大模型接力完成剩余推理
def llm_relay(question, partial):

    sys_p = ("You are a helpful assistant completing a task partially solved by a smaller "

# 并发 relay: 线程池 + 超时降级, 失败样本计 0 奖励不阻塞整批
def relay_concurrent(jobs, workers=4):
    """P2-16: relay 并发。jobs=[(idx, question, partial)] -> {idx: (cont,tin,tout)}"""
    res = {}
    with ThreadPoolExecutor(max_workers=workers) as pool:
        futs = {pool.submit(llm_relay, q, p): i for i, q, p in jobs}
        for fut in futs:
            i = futs[fut]
            try:
                res[i] = fut.result()
            except Exception as e:
                log.warning("relay fail job %s: %s", i, str(e)[:60])
                res[i] = ("", 0, 0)
    return res


# 组采样: 同一题采 G 条路径, 组内互比产生相对优势(GRPO 核心, 无需 Critic)
def rollouts(model, tok, q, n=G):
    prompt = (f"<|im_start|>system\n{SYSTEM_PROMPT}<|im_end|>\n"
              f"<|im_start|>user\n{q} Please reason step by step, and put your final "
              f"answer within \\boxed{{}}.<|im_end|>\n<|im_start|>assistant\n<think>\n")
    prompt_ids = tok(prompt, return_tensors="pt", add_special_tokens=False)["input_ids"]
    paths = []
    for _ in range(n):
        ids = prompt_ids.to(model.device)
        with torch.no_grad():
            o = model.generate(**ids, max_new_tokens=MAX_NEW, do_sample=True,
                               temperature=0.9, top_p=0.95)
        gen_ids = o[0][ids["input_ids"].shape[1]:]
        text = tok.decode(gen_ids, skip_special_tokens=False)
        n_slm = len(gen_ids)
        cost = n_slm * PRICE["slm"] / 1e6
        handed = TAU in text
        paths.append({"text": text, "gen_ids": gen_ids.tolist(),
                      "n_slm": n_slm, "handed": handed, "cost": cost})
    # 并发 relay (P2-16)
    jobs = [(i, q, p["text"].split(TAU)[0]) for i, p in enumerate(paths) if p["handed"]]
    relays = relay_concurrent(jobs) if jobs else {}
    for i, p in enumerate(paths):
        if p["handed"] and i in relays:
            cont, tin, tout = relays[i]
            p["text"] = p["text"].split(TAU)[0] + cont
            p["cost"] += (tin * PRICE["llm_in"] + tout * PRICE["llm_out"]) / 1e6
    return paths


# 真·策略梯度: 仅对生成 token 求 log_prob 乘组内优势, 偏离参考模型由 KL 约束
def grpo_step_loss(model, tok, path, adv):
    """P0-6: 真·策略梯度 - 组内优势 x 生成token的log_prob均值(仅SLM生成部分)

    注意: v2 版本此处仍存在实现缺陷 —— 未把 prompt 上下文编码进前向,
    导致 log_prob 条件缺失, 需进一步修复 (见第四章末的待修清单)。
    """
    ids = tok(path["text"], return_tensors="pt", add_special_tokens=False)["input_ids"][0]
    n_gen = min(path["n_slm"], len(ids))
    if n_gen <= 0 or abs(adv) < 1e-6:
        return None
    gen = ids[-n_gen:].unsqueeze(0).to(model.device)          # 仅 SLM 生成的 token
    logits = model(input_ids=gen).logits
    log_probs = torch.log_softmax(logits[:, :-1].float(), dim=-1)
    tgt = gen[:, 1:]
    selected = log_probs.gather(-1, tgt.unsqueeze(-1)).squeeze(-1)   # [1, T-1]
    loss = -(adv * selected).sum() / (selected.shape[1] + 1e-6)
    return loss

  • 奖励函数：acc − λ × (cost / base_cost)，其中 base_cost 预计算为纯大模型基线，缓存进 JSON 避免重复调用。
  • 组内优势：adv = (r − mean) / std，G 条路径互相对比，天然淘汰「磨叽半天才交接」的路径。
  • P0-6 待修：grpo_step_loss 未把 prompt 编码进前向，导致 log_prob 条件缺失；且交接路径下 ids[-n_gen:] 可能取到大模型续写的 token。正确写法需把 prompt+生成拼接后编码，只对 [prompt_len-1, prompt_len+n_slm-1) 区间求 log_prob。
  • REINFORCE 而非 PPO-clip：当前实现是单步 REINFORCE + 组内基线，没有 importance ratio 裁剪。需说明是「GRPO 简化版」。

# 成本计价器: 分别累计小模型/大模型 token 用量, 对齐官方计价协议
class CostMeter:
    tokens: dict = field(default_factory=lambda: {
        "slm_in": 0, "slm_out": 0, "llm_in": 0, "llm_out": 0})
    prices: dict = field(default_factory=lambda: dict(PAPER_PRICES))

    def add(self, kind, n):
        self.tokens[kind] += int(n or 0)

    def cost(self):
        return sum(self.tokens[k] / 1e6 * self.prices[k] for k in self.tokens)

    def summary(self):
        return {**self.tokens, "cost_usd": round(self.cost(), 6)}


# 协同引擎: 小模型先答, 触发 offload 标记则交大模型接力, 全程计价
class CollaborateEngine:
    def __init__(self,
                 slm_base_url, slm_model,
                 llm_base_url, llm_model, llm_api_key="EMPTY",
                 max_tokens=8192, temperature=0.1,
                 prices=None):
        self.slm = OpenAI(base_url=slm_base_url, api_key="EMPTY")
        self.llm = OpenAI(base_url=llm_base_url, api_key=llm_api_key)
        self.slm_model = slm_model
        self.llm_model = llm_model
        self.max_tokens = max_tokens          # 论文: 小模型+大模型共享的总预算
        self.temperature = temperature
        self.prices = prices or dict(PAPER_PRICES)

    # ---------- 小模型: 官方 /v1/completions + stop 截断 ----------
# 小模型补全: stop=[<|llm_offload|>] 截断, 并把 stop 串回读拼接保证上下文连续
    def slm_generate(self, question, extra_system=None):
        """返回 (raw_text, usage)。raw_text 含 <|llm_offload|> 则触发了交接。"""
        sys_prompt = extra_system or SYSTEM_PROMPT
        prompt = (
            f"<|im_start|>system\n{sys_prompt}<|im_end|>\n"
            f"<|im_start|>user\n{question}{PROMPT_SUFFIX}<|im_end|>\n"
            f"<|im_start|>assistant\n<think>\n"
        )
        resp = self.slm.completions.create(
            model=self.slm_model,
            prompt=prompt,
            temperature=self.temperature,
            max_tokens=self.max_tokens,
            stop=[OFFLOAD_TAG],
        )
        ch = resp.choices[0]
        text = ch.text or ""
        # safety: 服务端省略 stop 串时补回 (官方同款 fallback)
        if OFFLOAD_TAG not in text and ch.finish_reason == "stop":
            sr = getattr(ch, "stop_reason", None) or ""
            if OFFLOAD_TAG in str(sr):
                text += OFFLOAD_TAG
        usage = resp.usage
        return text, {"prompt_tokens": usage.prompt_tokens,
                      "completion_tokens": usage.completion_tokens}

    # ---------- 大模型: 官方交接协议 ----------
# 大模型接力: 按 CE 协议把小模型已生成内容作为前缀续写
    def llm_relay(self, question, slm_raw):
        """单次交接。返回 (final_text, llm_usage)。"""
        # 剥离: tag 前缀(去掉 think 标签) -> <part_think>
        prefix = slm_raw.split(OFFLOAD_TAG)[0]
        prefix = prefix.replace("<think>", "").replace("</think>", "").strip()
        partial = f"<part_think>{prefix}</part_think>"

        messages = [
            {"role": "system", "content": REMOTE_HANDOFF_PROMPT},
            {"role": "user", "content": f"{question}{PROMPT_SUFFIX}"},
            {"role": "assistant", "content": partial},
        ]
        budget_left = max(0, self.max_tokens - getattr(self, "_slm_completion", 0))
        resp = self.llm.chat.completions.create(
            model=self.llm_model,
            messages=messages,
            max_tokens=budget_left,
            temperature=self.temperature,
            extra_body={"chat_template_kwargs": {"enable_thinking": True}},
        )
        msg = resp.choices[0].message
        think = getattr(msg, "reasoning_content", None) or getattr(msg, "reasoning", "") or ""
        content = msg.content or ""
        usage = resp.usage
        final = f"<think>{prefix}{think}</think>{content}"
        return final, {"prompt_tokens": usage.prompt_tokens,
                       "completion_tokens": usage.completion_tokens}

    # ---------- 主入口 ----------
# 推理主入口: 一次调用完成 小模型->判定->交接->计价 全流程
    def infer(self, question):
        meter = CostMeter(prices=self.prices)
        self._slm_completion = 0   # P1-9: reset per-infer
        raw, su = self.slm_generate(question)
        meter.add("slm_in", su["prompt_tokens"])
        meter.add("slm_out", su["completion_tokens"])
        handed = OFFLOAD_TAG in raw

        if handed:
            self._slm_completion = su["completion_tokens"]
            final, lu = self.llm_relay(question, raw)
            meter.add("llm_in", lu["prompt_tokens"])
            meter.add("llm_out", lu["completion_tokens"])
        else:
            final = raw

        return {
            "question": question,
            "raw_slm": raw,
            "output": final,
            "handed_off": handed,
            "usage": meter.summary(),
        }

def score_one(response, answer):

    gt = boxed_socre.extract_ground_truth_boxed(answer)

        pn, gn = normalize_num(pred), normalize_num(gt)

            return 1, "numeric_fallback"
    return 0, "wrong"

# 小模型补全封装: 记录输入/输出 token 数, 用于成本计价
def call_small_completion(
    prompt: str, *, small_base_url: str, small_model: str, max_tokens: int
) -> tuple[str, dict[str, int]]:
    """llama.cpp 原生 /completion 端点: 精确返回 stopped_word/stopping_word,
    可区分 EOS 自然结束与 offload stop 截断 (OpenAI /v1 端点二者混为 finish=stop)。"""
    base = small_base_url.rstrip("/")
    if base.endswith("/v1"):
        base = base[: -len("/v1")]
    url = f"{base}/completion"
    body = {
        "model": small_model,
        "prompt": prompt,
        "temperature": TEMPERATURE,
        "n_predict": max_tokens,
        "stop": [OFFLOAD_TOKEN],
    }
    resp = requests.post(url, json=body, timeout=1800.0)
    resp.raise_for_status()
    data = resp.json()
    text = str(data.get("content") or "")
    if data.get("stopped_word") and data.get("stopping_word") == OFFLOAD_TOKEN:
        # 官方语义 include_stop_str_in_output=True: 补回 stop 串
        text = text + OFFLOAD_TOKEN
    usage = {
        "prompt_tokens": int(data.get("tokens_evaluated") or 0),
        "completion_tokens": int(data.get("tokens_predicted") or 0),
        "total_tokens": int(data.get("tokens_evaluated") or 0) + int(data.get("tokens_predicted") or 0),
    }
    return text, usage


# 批量执行: 线程池并发, 收集每题 token 计价明细
def run_small_batch(
    questions: list[str],
    *,
    tokenizer,
    small_base_url: str,
    small_model: str,
    max_tokens: int,
) -> tuple[list[str], list[list[int]], list[dict[str, int]]]:
    """并发跑小模型阶段, 每完成一题向 progress 文件追加一行。"""
    prompts = [format_prompt(tokenizer, q) for q in questions]
    raw_responses = [""] * len(questions)
    usages: list[dict[str, int]] = [
        {"prompt_tokens": 0, "completion_tokens": 0, "total_tokens": 0} for _ in questions
    ]
    completion_ids: list[list[int]] = [[] for _ in questions]

    def _run(idx: int) -> tuple[int, str, dict[str, int]]:
        text, usage = call_small_completion(
            prompts[idx],
            small_base_url=small_base_url,
            small_model=small_model,
            max_tokens=max_tokens,
        )
        try:
            with open(r"D:\project\2026\202609\Small_ask_big\logs\gsm8k_1k.progress", "a", encoding="utf-8") as pf:
                pf.write(f"{idx},{len(text)}\n")
        except OSError:
            pass
        return idx, text, usage

    workers = max(1, min(SMALL_MAX_WORKERS, len(questions)))
    with ThreadPoolExecutor(max_workers=workers) as pool:
        futures = [pool.submit(_run, i) for i in range(len(questions))]
        for fut in tqdm(as_completed(futures), total=len(questions),
                        desc="[small] generate", unit="sample"):
            idx, text, usage = fut.result()
            raw_responses[idx] = text
            usages[idx] = usage
            completion_ids[idx] = [0] * int(usage.get("completion_tokens", 0))

    return raw_responses, completion_ids, usages


# 大模型接力批处理: 小模型 raw 输出统一交大模型完成并计价
def relay_with_llm(raw_responses, questions, *, api_key, completion_ids,

DROP_KEYS = {"qwen35.nextn_predict_layers", "qwen35.attention.recurrent_layers"}
SCALAR_ADD = {
    GGUFValueType.STRING: "add_string", GGUFValueType.UINT8: "add_uint8",
    GGUFValueType.INT8: "add_int8", GGUFValueType.UINT16: "add_uint16",
    GGUFValueType.INT16: "add_int16", GGUFValueType.UINT32: "add_uint32",
    GGUFValueType.INT32: "add_int32", GGUFValueType.UINT64: "add_uint64",

}
# GGUF 字节流按 utf-8 解码, 非法字节容错替换
def decode_bytes(raw): return bytes(raw).decode("utf-8", "replace")
reader = GGUFReader(SRC)
writer = GGUFWriter(DST, "qwen35")
patched = []
# 遍历 GGUF 元数据字段, 定位需要修补的 token_type 相关项
for name, field in reader.fields.items():
    if name in DROP_KEYS:
        patched.append(("DROP", name)); continue
    if name == "qwen35.block_count":
        writer.add_uint32(name, 32); patched.append(("block_count->32", name)); continue
    if name == "general.architecture":
        continue
    types = list(field.types); vt = GGUFValueType(types[0])
    if vt == GGUFValueType.ARRAY:
        it = GGUFValueType(types[1])
        if it == GGUFValueType.STRING:
            vals = [decode_bytes(field.parts[di]) for di in field.data]
        else:
            np_types = {GGUFValueType.UINT8: np.uint8, GGUFValueType.INT8: np.int8,
                GGUFValueType.UINT16: np.uint16, GGUFValueType.INT16: np.int16,
                GGUFValueType.UINT32: np.uint32, GGUFValueType.INT32: np.int32,
                GGUFValueType.UINT64: np.uint64, GGUFValueType.INT64: np.int64,
                GGUFValueType.FLOAT32: np.float32, GGUFValueType.FLOAT64: np.float64,
                GGUFValueType.BOOL: np.bool_}
            flat = np.concatenate([field.parts[di] for di in field.data])
            vals = flat.astype(np_types[it]).tolist()
        # 关键补丁: <|llm_offload|>(248077) token_type CONTROL->NORMAL
        # llama.cpp detokenize 跳过 special token 文本, 导致 offload 标记不可见/stop 失效
        if name == "tokenizer.ggml.token_type" and len(vals) > 248077:
            patched.append((f"token_type[248077]: {vals[248077]} -> 1(NORMAL)", name))
            vals[248077] = 1
        writer.add_array(name, vals)
    elif vt in SCALAR_ADD:
        v = field.parts[field.data[0]]
        val = decode_bytes(v) if vt == GGUFValueType.STRING else v[0]
        getattr(writer, SCALAR_ADD[vt])(name, val)
    else:
        patched.append(("SKIP", name))
n = 0
for t in reader.tensors:
    writer.add_tensor(t.name, t.data, raw_dtype=t.tensor_type); n += 1
writer.write_header_to_file(); writer.write_kv_data_to_file(); writer.write_tensors_to_file(); writer.close()
