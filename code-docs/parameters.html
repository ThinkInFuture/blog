参数说明 · vLLM Ascend 可调参数大全

五层参数体系：vllm-ascend 可调的东西分五层 —— 层1 vLLM 原生启动参数（上游标准）、层2 speculative-config（投机解码，15 种 proposer）、 层3 compilation-config（图/编译模式）、层4 additional-config = AscendConfig（昇腾私有 122 字段，绝大部分调优项在这层）、 层5 环境变量（正逐步收编进层4 的 pydantic）。日常调优 90% 落在层 4。

层 2 · speculative-config（投机解码，15 种 proposer）

参数说明
methodproposer 选择：deepseek_mtp（DeepSeek/GlmMoeDsa 专用，单 draft KV 组——已验证路径）/ mtp（Step3.5 式通用 MTP，每个 MTP 层独立 KV 组——GLM-5.2 prefix 案相关）/ eagle3 / dflash / dflash2 / dspark / medusa / ngram / suffix

proposer 实现：vllm_ascend/spec_decode/ （mtp.py = deepseek_mtp · step3p5.py = mtp · eagle_proposer.py = eagle3 · dflash_proposer.py …）

参数说明

编译体系（三条编译链，毕昇在哪条上）

链编译对象编译器触发时机产物
链 1csrc 的 host 侧封装（torch_binding.cpp 等，C++17）CMake + gcc/clangpip install / setup 构建vllm_ascend_C 扩展（torch.ops._C_ascend.*）
链 2AscendC device kernel（csrc/**/op_kernel）+ op_host tilingbisheng（毕昇，随 CANN 包发布）+ catlasscsrc/build_aclnn.sh（源码构建算子）ACLNN 算子二进制
链 3Triton kernel（vllm_ascend/ops/triton/*.py：dsa_cp、lightning_indexer、slot_mapping、eplb…）triton-ascend==3.2.2 运行时 JIT运行时首次执行 / shape 变化缓存的 NPU kernel
旁torch.compile / ACLGraphDynamo 捕获 + aclgraph replaywarmup（cudagraph_mode 开启时）图句柄（不产生新机器码）

毕昇定位：csrc/build.sh 中 BISHENG_REAL_PATH=$(which bisheng)——毕昇随 CANN 工具包发布， 只在源码构建 AscendC 算子时需要（pip 官方 wheel 已预编译）。运行时 Triton kernel 由 triton-ascend JIT 走 CANN 编译栈（链 3）。 build.sh 缺 bisheng 的报错原文："bisheng compilation tool not found, Please check whether the cann package or environment variables are set."
