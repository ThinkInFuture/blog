勘误与口径说明

  • 多流类参数名单勘误：此前目标建议书里写的 ascend_scheduler_config 在当前代码树中不存在（ascend_config.py 全量核对）。多流类实际为三参数： enable_cpu_binding / multistream_dsv4_dsa_overlap（默认均 true）/ multistream_overlap_shared_expert（默认 false）。md 版建议书已同步修正。
  • 分类口径：按"解决什么问题"而非 YAML 层级——dyntra_lb_config 的 bubble_threshold 归调度类；mega_moe_max_tokens / enable_reduce_sample 是顶层字段但按作用归调度类。
