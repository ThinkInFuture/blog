读法

所有特性开关集中在 deepinfer/environ.py 一个文件：EnvVar 非数据描述符按需解析 os.getenv，类型工厂（bool/int/float/str/choice/lambda）给默认值。设为环境变量即生效；几个高频组：EPLB 专家均衡、MTP 投机解码（USE_NEXTN_DECODE=5 可关）、YoCo 截断（TRUNCATION_MODE=off|mask|compact）、调度（PREFILL_ATTEMPT_INTERVAL=70 / ANY=100 / ZERO_OVERHEAD_SCHEDULING）、图捕获（CUDAGRAPH_BATCH_SIZE_INTERVAL=8）、结构化输出（XGRAMMAR 系列）。
