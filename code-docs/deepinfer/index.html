DeepInfer 架构总览

DeepSeek 开源生产推理框架 · 支撑 V4.1-Flash · deepseek-ai/DeepInfer @ 774ce24 · Apache-2.0

一、项目简介

DeepInfer 是 DeepSeek 生产推理引擎的开源版，支撑 DeepSeek-V4.1-Flash 大规模线上服务。官方 Q&A 给出的生产规模：单集群每天服务 155 万亿 token，整体营收 38 美元/GPU·小时（谷时电价口径）。

README 致谢段写明 "originally built primarily on vLLM"，另受 SGLang 与 TensorRT-LLM 启发——五层骨架与 vLLM 相同，但为 V4.1-Flash 的 CED/YOCO 架构与大规模部署深度定制。六大特性：Wide-EP（decode EP64-128）+ EPLB 专家均衡、DSpark 置信度变长验证、SWA bounded replay、异步调度、批不变与确定性采样、结构化输出（xgrammar）。

开源边界：引擎本体（离线推理可用）；KV cache 存储系统与跨副本负载均衡未含（耦合内部基础设施），设计在 doc/inference_deployment_qa.md（312 行）展开；伴生开源 deepseek-recipe（Rust 编解码组件）。

三、上下游关系

3.1 上游：vLLM（继承复用）

DeepInfer 不是 vllm-ascend 那样的插件，而是基于一年多前的 vLLM 早期版本 fork 后深度定制的独立引擎。上游提供：LLMEngine 类体系与 EngineArgs 装配、Worker/ModelRunner/CudaGraphRunner 骨架、Scheduler 调度骨架（连续批处理思想）、Platform 平台抽象、采样与 RoPE 参考实现。

3.2 下游：DeepInfer（重写/新增）

engine/ 主循环重排（异步调度 + ALL/ANY 集体 prefill）、worker/ cache_engine 全重写（StateBlock + SWA state）、v4_modules 26 文件（CED 与 YOCO 落地）、tilelang_ops 算子库（CUDA 25 + AscendC 33）、npu_ops / ve / structure_output 三个定制新目录。

3.3 依赖关系

vllm-ascend 靠 Platform 接口外挂进 vLLM；DeepInfer 把 vLLM 的代码长进了自己身体里——主包 4.6 万行，fork 后删掉通用框架的多车型包袱，换来在 v4_modules 里直写 CED 投影分发与 SWA ring buffer 语义的自由。

四、整体架构与请求处理流程

4.1 请求处理十步（离线推理路径）

  1. LLM 入口：entrypoints/llm.py 的 LLM.generate 接收 prompt 与 SamplingParams（seq_seed / so_args 在此进引擎）；
  2. 引擎会话：engine/llm_engine.py（1,030 行）创建会话、装配 EngineArgs，多模态请求先走 ve/ 视觉编码；
  3. 元数据装配：C++ prepare_prompt_v4 产出 InputMetadataV4——YoCo 截断（mask/compact）与块 KV 加载计划在这一步定形；
  4. 集体 prefill 调度：ALL 档（全员有活才做，间隔 70 步）或 ANY 保底档（100 步），CPU 与 GPU 异步重叠；
  5. Worker 执行：worker/worker.py 驱动 model_runner 装批，cache_engine 按槽位取 SWA state 与块 KV；
  6. 模型前向：v4_modules 逐层——编码器 20 层算 KV，CED 投影分发给解码器块 KV，SWA KV 走 bounded replay 只重算 128 token；
  7. 稀疏注意力：index_attn 稀疏 indexer 选块，tilelang_ops 的 attention/candidate_blocks/load_paged_kv_cache 完成计算（FP4 主 KV + ue8m0 scale）；
  8. MoE：mlp.py DeepseekMoE 走 mega-MoE 融合路径，EPLB 按统计窗重排专家；
  9. 采样：fused_sample 融合采样；DSpark 开启时 ConfidenceHead 打分，按置信度截取验证前缀；
  10. 输出：结构化输出请求由 matcher 推进自动机生成 token 掩码，结果回 LLM 返回。
