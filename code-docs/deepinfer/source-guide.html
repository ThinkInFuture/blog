二、五层逐层展开

第 1 层 · 入口（entrypoints/llm.py）

看 llm.py 源码

LLM 类：generate 接 prompt 与 SamplingParams。看什么：seq_seed / so_args 怎么进引擎、多模态输入何时分流去 ve/。

第 2 层 · 引擎（engine/，6 文件）

看 llm_engine.py 源码

llm_engine.py（1,030 行）是主循环心脏：会话装配、ALL/ANY 两档集体 prefill（间隔 70/100 步）、异步调度重叠。arg_utils/engine_type 辅助装配；profile_server 是 profiling 服务。看什么：主循环里 schedule 与 forward 的重叠关系。

第 3 层 · 执行（worker/，10 文件）

看 cache_engine.py 源码

worker.py 驱动 model_runner 装批；cache_engine.py 管缓存生命周期（StateBlock 槽位 + SWA state）；cuda_graph_runner 与 dflash_cuda_graph_runner 两套图捕获；decode_perf_cache 记录 decode 性能。看什么：SWA state 的取还与块 KV 的加载计划（与 csrc/block_load_plan 对应）。

第 4 层 · 模型（model_executor/models/v4_modules/，26 文件）

看 attn.py 源码

attn.py（1,009 行）MLA 运行时（CED 投影分发 + SWA ring buffer）；index_attn 稀疏索引；cross_layer 跨层共享；engram 记忆块；hc/hc_blocks/hc_lazy 多头一致性；mlp.py DeepseekMoE。看什么：编码器 KV 怎么被投影分发、SWA 的 128 token 重算边界。

第 5 层 · 算子（model_executor/layers/tilelang_ops/，33 py）

看 candidate_blocks.py 源码

三层结构：接口层（ops.py 按平台分发）+ 参考实现 + 测试。attention / candidate_blocks / load_paged_kv_cache / fused_sample 四类核心；cuda 25 文件与 asc 33 文件（AscendC）双平台。看什么：ops.py 的平台分发逻辑，再挑 attention 一个算子读三层。

C++ 侧（csrc/，33 文件）

pybind.cpp 总入口；engine/ 里 zos.cpp（零开销调度）、prepare_tensor_input_v4.cpp（yoco 截断 mask/compact 两布局）、block_load_plan.cpp（块 KV 加载计划）、scheduler.hpp（ALL/ANY 集体 prefill 的 _schedule）；graph_timer 分 CUDA/昇腾两版。Python 侧 input_metadata 包是它们的薄封装。

三、配合工具

逐文件清单：全景源码（270 文件逐个：docstring 职责 + 全部顶层符号行数）。单文件细读：任意页面点「查看源码」直达镜像查看器。开关速查：参数说明（55 个环境变量）。

读码顺序建议：十步流程（总览 4.3）→ llm_engine 主循环 → cache_engine → v4_modules/attn.py → tilelang_ops/ops.py → 回头读 csrc 四件（zos / prepare_tensor_input_v4 / block_load_plan / scheduler.hpp）。
