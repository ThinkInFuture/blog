DeepInfer 使用说明

从零装到跑出第一个 token · 双平台（NVIDIA SM100 / 昇腾 950）· 离线推理路径 · 2026-10-21

一、安装（四步）

  1. 克隆仓库：git clone https://github.com/deepseek-ai/DeepInfer；
  2. 选平台依赖（二选一）：
    NVIDIA：pip install -r requirements-nvidia.txt（torch 2.13.0+cu132、flash-attn-4）
    昇腾：pip install -r requirements-ascend.txt（torch 2.13.0+cpu、torch-npu 2.13.0rc1，需 CANN 9.2）；
  3. 装引擎本体：pip install -e .（setup.py 92 行，构建面刻意最小；不需要另装 vLLM——fork 源码已在主包内）；
  4. 验证：python -c "import deepinfer"，再跑 examples。

二、跑第一次推理

入口在 examples/offline_inference.py：构造 LLM（指定模型路径）、传 prompts 与 SamplingParams，同步拿结果。请求内部走十步流程（架构总览 4.3）：集体 prefill 调度 → v4_modules 前向 → 稀疏注意力 → 融合采样。

常用 SamplingParams 能力：seq_seed（确定性采样）、so_args（结构化输出，xgrammar 文法）、MTP 投机解码（默认 USE_NEXTN_DECODE=5，置 0 关闭）。

看 llm_engine.py 源码 看 llm.py 入口

说明

1. 开源版提供离线推理路径（LLM 类）；线上服务化的 KV 存储与跨副本负载均衡未含（耦合内部基础设施），设计见 doc/inference_deployment_qa.md

2. 特性开关全部走环境变量（DEEPINFER_*），集中在 environ.py——完整清单见 参数说明

3. 批不变与确定性采样当前仅 NVIDIA 平台；昇腾侧算子经 tilelang_ops/asc（AscendC）

三、常见问题

Q：要不要先装 vLLM？不需要——DeepInfer 是 fork 定制的独立引擎，vLLM 骨架源码已在主包内。

Q：支持哪些模型？为 DeepSeek V4.1-Flash 单车型深度调校（CED/YOCO/SWA/MoE）；模型侧全部代码在 v4_modules。

Q：怎么看引擎内部在干什么？engine/profile_server.py 提供 runtime profiling HTTP 服务（fastapi/uvicorn，dev 依赖）；timer.py 三态计时器配 csrc/graph_timer。

Q：多机怎么起步？先用 deep_cluster 探测拓扑，再按 Wide-EP 配置（decode EP64-128）；细节见架构总览第十章模块协作。
