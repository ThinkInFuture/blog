DeepSeek V4.1-Flash 登陆昇腾：框架支持与 Engram 主机卸载

DeepSeek V4.1-Flash 已合入 main PR #16925 · commit 0deca3181 · 2026-09-21 合入 · 73 文件 +10554/-665 · 代码基线 a71b766ce

一、背景：DeepSeek 发了个新模型，昇腾为什么跑不动

2026-09-10，DeepSeek 发布 DeepSeek-V4.1-Flash： 552B 参数 MoE（每 token 激活 prefill 8B / decode 16B），训练 64K 稀疏注意力、外推 1M 上下文。 它的主线思路是把 KV Cache 压到极限，靠三件新架构武器：

武器一句话关键数字
CED
因果编码器-解码器		解码器的全局 KV 不由自己的 20 层逐层产生——输入先过 20 层因果编码器，再由末端隐状态一次性投影出解码器要用的全局 KV持久 KV ≈ V4-Flash 的 1/8
CSA2
压缩稀疏注意力 2		每层静态分派 Full / Reindex / Reuse 三种模式，跨层共享主 KV 与索引 K、复用 Top-K 索引；主 KV 用 FP4 存全局 KV 890 B/token
Engram
条件记忆		196B 参数的稀疏查表记忆：token 哈希命中才注入隐状态，不命中不花访存按需访问，不全驻显存

三者相乘，得到 890 字节/token 的全局 KV + 1M 上下文。上游 vLLM main 已带 V4.1 模型实现 （vllm commit 84030bbe）—— 但昇腾一处都跑不动。

读图指引：下面这张图回答一个问题——请求进来后，第一个断点在哪？ 看那四条带 ✗ 的虚线：注意力后端、缓存分配、Engram 存储、DSpark 注册， 每一处都是"上游要、昇腾没有"。改动前四条全断（本图）；改动后四条全通（图3）。

二、前史：这个需求为什么是第二次提交

它不是一次成功的普通 PR。#16544 曾把完整框架集成首次合入，但与当周 main 产生集成冲突，被 #16905 回退—— 于是有了图1 里"改了却又没有"的空窗期。

三、诉求与方案：在 A3 上完整跑起来，五件套补齐

诉求不是"能 import"，而是教程里的完整部署形态：A3 双机 16 卡（DP4×TP8+EP）、 1M 上下文、block 128、W8A8 权重，能出 token、能开全量解码图、能跑 DSpark 投机 （教程）。 这决定了改动必然横跨模型、注意力、缓存、算子、Runner 五层——即"五件套"：

四、实现：先看执行链路，再读三段代码

def get_layer_tuples(specs):
    """Return DSV4-style ordered layer tuples and their physical page sizes."""
    mla = {name for name, spec in specs.items() if isinstance(spec, AscendMLAAttentionSpec)}
    state = sorted((name for name, spec in specs.items() if isinstance(spec, CircularBufferSpec)), key=_layer_number)
    swa = {name for name, spec in specs.items() if isinstance(spec, AscendSlidingWindowMLASpec)}
    ...
    for slot_idx, kv_name in enumerate(full):
        prefix = kv_name.rsplit(".", 1)[0]
        index_name = prefix + ".indexer.k_cache"  # ⚡索引器 K 缓存与全局 KV 同槽配对
        index_spec = specs[index_name]
        kv_spec = specs[kv_name]
        aliases = ([state[slot_idx]] if slot_idx < len(state) else []) + target_swa[slot_idx :: len(full)]
        kv_bytes = kv_spec.unpadded_page_size_bytes
        index_bytes = index_spec.unpadded_page_size_bytes
        ...
        capacity = max(  # ⚡页容量=槽内最大成员：索引 K 与 FP16 scale 排在 KV 之后同页（压缩比2：64 行/131072B；压缩比1：128 行/147712B）
            kv_bytes + index_bytes,
            *(specs[name].unpadded_page_size_bytes for name in aliases),
        )
        layer_tuples.append((kv_name, index_name, *aliases))  # ⚡一个块 ID 同时定位四类缓存（层外置）

代码 C（执行）· AscendDSAV41Impl.forward：三阶段串起来（attention/dsa_v41.py:538，摘录）
看这段代码，只需抓一个点：Q 投影与 KV 写入是双流并行的（⚡那一行，即图3 阶段①）； 随后的两步依次落在阶段②（_select_sparse_indices）和阶段③（npu_sparse_flash_mla），其余都是收尾。
def forward(self, attn, positions, hidden_states, output: torch.Tensor | None = None):
    # ↳ 自定义算子调用方传入图稳定输出缓冲：O 投影结果直写，免去图边界的整张拷贝（⚡昇腾图优化）
    if output is None:
        output = torch.empty_like(hidden_states)
    forward_context = get_forward_context()
    if forward_context.attn_metadata is None:
        output.zero_()  # ↳ dummy 前向（剖析/捕获期）直接清零返回
        return output
    metadata = self._get_layer_metadata(forward_context.attn_metadata)
    self._prepare_inputs_and_caches(attn, hidden_states, metadata, forward_context.attn_metadata)
    num_tokens = metadata.swa.num_actual_tokens
    if num_tokens:
        positions = metadata.positions[:num_tokens]
        cos, sin = metadata.rope(attn.rotary_emb.layername, num_tokens)
        q, qr = self._prepare_queries(attn, hidden_states, positions, cos, sin, metadata)  # ⚡阶段①：双流 Q 投影∥KV Cube
        compressed_indices = self._select_sparse_indices(attn, hidden_states, qr, positions, cos, sin, metadata)  # ⚡阶段②：QLI V3 候选三模式
        attention_output = self._forward_attention(attn, q, metadata, compressed_indices)  # →NPU 阶段③：SparseFlashMla 双阶段
        torch.ops._C_ascend.inplace_partial_rotary_mul(  # →NPU：输出侧逆 RoPE 原地完成，不落临时张量
            attention_output.unsqueeze(1),
            cos,
            -sin,
            rotary_mode="interleave",
            partial_slice=[attn.nope_head_dim, attn.head_dim],
        )
    else:
        heads = attn.n_heads if getattr(attn, "enable_dsa_cp", False) else attn.n_local_heads
        attention_output = hidden_states.new_empty((0, heads, attn.head_dim))
    self._project_output(attn, attention_output, hidden_states, metadata, projected=output)
    return output
